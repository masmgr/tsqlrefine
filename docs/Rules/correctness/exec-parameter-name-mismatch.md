# exec-parameter-name-mismatch

## Summary

Reports named `EXEC` arguments that are not present in the resolved procedure signature.

## Examples

```sql
EXEC dbo.FindUser @userId = 42; -- signature contains @id, not @userId
```

Parameter matching is case-insensitive. Dynamic, external, unresolved, and ambiguous calls are
skipped. The rule requires an object catalog generated by `schema collect-objects`.

## Category

Correctness

## Severity

Error

## Fixable

No
